# Security

This is a development project, not a production service. There is no supported stable pack release or guaranteed response time yet.

Do not post credentials, private server details, personal world data or exploitable vulnerability details in public issues or pull requests.

For a repository-specific issue, use GitHub’s **Security → Report a vulnerability** private reporting route. If that route is unavailable, do not post the sensitive material publicly; contact the owner through an existing private channel to agree a safe route.

Report vulnerabilities in third-party mods to their maintainers through their own security channels. This repository does not replace upstream security support.

Local pattern scans and file hashes are useful checks, but neither guarantees that a mod or download is safe to run. Use disposable development instances and backups when separately testing game changes.
